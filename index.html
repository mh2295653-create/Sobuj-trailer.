📧 Email Alerts Configuration (EmailJS)

📌 Setup Instructions
1. Create EmailJS account.
2. Add Email Service and copy Service ID.
3. Create template with variables: {{staff_name}}, {{action}}, {{order_no}}, {{customer}}, {{total_price}}, {{paid_amount}}, {{baki_amount}}, {{expected_delivery_date}}, {{datetime}}.
4. Template fields: To Email = {{to_email}}, From Name = {{from_name}}, Reply To = {{reply_to}}.
5. Copy Public Key from Account → General.

Security note: EmailJS public key is browser-side by design. This project does not hardcode your EmailJS IDs into source files; they are stored only in this browser after you save them. Do not commit private service passwords or personal Gmail passwords to GitHub.

⚿ User Setup

For GitHub/static hosting, this is local browser authentication only. Credentials are stored as SHA-256 hashes in this browser. For real production use, use Firebase/Supabase authentication.
Security Status
Default admin and staff logins are stored as hashes only. Plain-text usernames and passwords are not displayed in the app and are not written in the source code.
